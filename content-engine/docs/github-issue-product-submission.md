## 参赛项目名称

**百炼公众号百宝箱**

面向公众号创作者和自媒体运营者的一站式 AI 内容工作台，覆盖题材发现、内容研究、正文创作、配图、公众号排版、草稿箱导入、发布登记和数据复盘。

- 当前状态：已部署至阿里云轻量应用服务器，处于功能预览阶段。当前地址为 HTTP，请勿在此地址输入真实 API Key、AppSecret 或其他生产凭证；正式开放配置测试前会启用 HTTPS。

## 我做了什么

公众号创作者通常需要在热点工具、搜索引擎、文档、AI 对话、生图工具、公众号后台和数据表格之间反复切换。题材、研究资料、写作经验、图片素材、排版模板和发布数据彼此割裂，每次创作都需要重新组织上下文。

我使用阿里云百炼和百炼 CLI，将这些工作整合为一条连续链路：

1. 从 RSS、网络搜索、文章链接和个人创意中发现题材。
2. 建立创作项目，整理事实、观点、结构、账号声音和视觉参考。
3. 完成来源研究、事实核验、公众号正文生成及多种修改任务。
4. 根据正文规划封面和段落插图，支持网络搜图、AI 生图、上传图片和素材库复用。
5. 选择公众号模板进行智能排版，并继续编辑正文、配图、开头和结尾。
6. 将审核后的内容导入微信公众号草稿箱，由用户在公众号后台正式发布。
7. 发布后登记公开文章链接，形成内容台账和复盘依据。

产品的核心不是单次生成一篇文案，而是让题材、账号声音、图片素材、排版模板和复盘记录形成可持续使用的工作资产。

```mermaid

  A[发现题材 / 个人创意 / 已有草稿] --> B[建立创作项目]
  B --> C[内容准备与研究]
  C --> D[生成并采用公众号正文]
  D --> E[策划并生成配图]
  E --> F[排版预览与确认]
  F --> G[导入公众号草稿箱]
  G --> H[公众号后台正式发布]
  H --> I[登记公开链接]
  I --> J[数据复盘]
  J --> K[人工复盘记录与下一次创作参考]
```

## 使用的工具

- **OpenWork / 百炼 CLI**：统一调用文本生成、内容分析、视觉策划和图像生成能力。
- **阿里云百炼模型**：按任务配置不同模型，处理资讯分析、来源核验、账号声音、正文生成、正文修改、配图策划、智能排版和 AI 生图。
- **Skill**：将公众号正文、来源核对、账号声音、视觉策划和排版规则封装为可复用任务能力，并输出结构化结果供用户确认。
- **检索与信息源**：Tavily、RSS、RSSHub 和公开网页读取。
- **公众号能力**：微信公众号开发者接口、草稿箱导入和服务器出口 IP 白名单检测。
- **工程技术**：React、TypeScript、Fastify、PostgreSQL、Redis、BullMQ、Nginx、systemd、Chrome/Playwright。

### 1. 首次配置首页

首页按照真实依赖顺序引导用户完成六项配置，并显示每项完成状态：

1. 阿里云百炼 API
2. 检索 API
3. 模型任务策略
4. 资讯来源
5. 微信公众号平台账号
6. 账号声音

每一步同时提供站内配置入口、具体操作说明和对应的外部官方链接。

### 2. 发现与创作项目

- 刷新 RSS 资讯源，搜索网络热点和关键词。
- 导入公开文章链接并读取内容。
- 创建“个人创意”，填写标题、题材和补充内容。
- 将个人创意合并到已有草稿，或建立独立创作项目。
- 在创作列表继续、筛选或删除项目。

### 3. 内容研究与公众号正文

- 整理主题、受众、事实、观点、结构、篇幅和写作策略。
- 通过网络检索补充来源，并进行来源交叉核对；结果由用户最终审核。
- 生成完整公众号正文，查看候选版本后由用户决定是否采用。
- 支持完整正文或选中文本的重构、润色、扩写和压缩。

| 动作 | 正确语义 |
| --- | --- |
| 生成正文 | 根据选题、研究资料、写作策略和账号声音生成第一版完整正文 |
| 重构 | 重新组织主题表达和文章结构，生成新的完整版本 |
| 润色 | 保留原文核心结构和事实，改善表达、节奏和可读性 |
| 扩写 | 在现有内容上补充论证、例子和必要细节 |
| 压缩 | 保留关键信息，删除重复表达并缩短篇幅 |

### 4. 账号声音

- 导入用户拥有使用权的历史文章作为写作参考。
- 提炼开场、结构、句式、读者关系、节奏和表达边界。
- 用户审核后保存为可复用的账号声音，并可设为默认声音。
- 保存的是写作规则，不复制参考文章的具体内容。

### 5. 配图与素材库

- 根据正式正文规划封面、主图和段落插图。
- 为每张图生成画面任务、搜索词和正向提示词。
- 将正文插图绑定到具体段落，并在完整段落后插入。
- 支持网络搜图、AI 生图、本地上传和素材库选择。
- AI 生图支持上传参考图或从素材库选择参考图。
- 提示词可编辑，图片可替换、移除或重新生成。
- 素材库使用图片瀑布流预览，支持跨项目复用。

### 6. 公众号排版

- 内置多套公众号排版模板并生成真实 HTML 预览。
- 支持使用 AI 对当前模板进行智能精排。
- 排版后仍可编辑标题、正文和正文图片。
- 支持个性开头和结尾，可使用文字、上传图片或素材库图片。
- 页面预览与导入公众号的正式草稿使用同一套渲染逻辑。

### 7. 发布与复盘

- 配置公众号 AppID、AppSecret 和服务器出口 IP 白名单。
- 将审核后的文章导入微信公众号草稿箱，并提供快捷查看入口。
- 正式发布由用户在公众号后台完成，产品不会自行推断发布状态。
- 发布后可粘贴公开文章链接，自动读取公开可获取的标题、封面、发布时间和部分互动数据。
- 支持文章台账、批量刷新和错误记录删除。
- 支持 D1、D3、D7 数据检查点和历史快照；微信公开页面没有提供或账号无权访问的数据会显示为空，不要求用户手工伪造数据。
- 支持填写总结、亮点、问题和下一步，形成单篇文章的人工复盘记录。

<summary><strong>功能使用手册</strong></summary>

### 一、注册与登录

1. 打开产品测试地址。
2. 注册账号并登录。
3. 系统自动创建个人工作空间，模型凭证、素材和创作项目按工作空间隔离。

### 二、完成首次配置

#### 第 1 步：配置阿里云百炼 API

1. 登录[阿里云百炼控制台](https://bailian.console.aliyun.com/)，创建 API Key。
2. 进入“设置 → 模型与 API → 阿里云百炼”。
3. 填写 API Key，保存并执行连接检测。
4. 同步当前账号可用的模型目录。

#### 第 2 步：配置检索 API

1. 登录 [Tavily](https://app.tavily.com/home)，创建 API Key。
2. 进入“设置 → 模型与 API → 检索 API”。
3. 保存并检测连接，确认状态可用。

#### 第 3 步：配置任务策略

1. 进入“设置 → 模型与 API → 任务策略”。
2. 为资讯分析、来源核验、选题推荐、账号声音、公众号正文、配图策划、智能排版和 AI 生图选择模型。
3. 保存并返回首页，确认任务策略状态已完成。

#### 第 4 步：配置资讯来源

1. 进入“设置 → 资讯来源”。
2. 启用已有 RSS 来源，或添加自定义 RSS 地址。
3. 可参考 [RSSHub 文档](https://docs.rsshub.app/) 获取更多来源。
4. 返回“发现”页面刷新资讯。

#### 第 5 步：配置公众号平台账号

1. 登录[微信公众号平台](https://mp.weixin.qq.com/)，获取 AppID 和 AppSecret。
2. 在“设置 → 平台账号”查看当前服务器出口 IP。
3. 将出口 IP 加入微信公众号开发者平台 IP 白名单。
4. 填写账号信息并检测连接。

#### 第 6 步：配置账号声音

1. 进入“设置 → 账号声音”。
2. 导入自己拥有使用权的历史文章链接并确认授权。
3. 审核系统提炼的写作规则，保存并按需设为默认声音。

### 三、创建内容项目

用户可以从三类入口开始：

- 在“发现”中刷新 RSS、搜索关键词或导入文章链接，再创建项目。
- 在“创作”中新建个人创意，填写标题、题材和补充内容。
- 从创作项目列表打开已有草稿，继续上次停留的阶段。

### 四、生成和修改正文

1. 确认主题、受众、内容类型、目标篇幅和账号声音。
2. 根据需要执行网络研究和来源核验。
3. 点击“生成正文”，等待任务完成。
4. 查看生成结果并决定是否采用。
5. 需要修改时选择重构、润色、扩写或压缩；也可先选中文本再执行局部修改。
6. 采用后的版本将成为后续配图和排版使用的正式正文。

### 五、完成配图

1. 进入“公众号配图”，点击策划配图。
2. 检查图片角色、段落位置、画面任务和提示词。
3. 按需编辑提示词，选择网络搜图、AI 生图、上传图片或素材库图片。
4. 检查封面和正文插图位置，保存后进入排版。

### 六、完成公众号排版

1. 选择排版模板并查看预览。
2. 按需输入精排要求并执行智能精排。
3. 继续编辑正文、配图、个性开头和结尾。
4. 应用修改并刷新预览，确认后保存公众号草稿。

### 七、导入公众号草稿箱

1. 进入“发布”，选择已完成的草稿和目标公众号。
2. 点击“导入公众号草稿箱”。
3. 导入成功后通过快捷入口查看结果。
4. 在微信公众号后台完成最终检查和正式发布。

### 八、登记发布并复盘

1. 文章正式发布后复制公开文章链接。
2. 进入“复盘”，添加已发布文章链接。
3. 系统读取可公开获取的信息并建立文章台账。
4. 使用批量刷新更新可获取的数据，在仪表盘中查看阅读、点赞、转发等字段和 D1/D3/D7 检查点。
5. 填写总结、亮点、问题和下一步，保存本篇文章的复盘记录。

## 项目亮点

1. **完整工作链路**：从题材发现一直覆盖到公众号草稿箱和发布后复盘。
2. **任务模型可配置**：用户可按质量、成本和模型能力为不同任务选择模型。
3. **Skill 化创作规则**：研究、写作、声音、视觉和排版规则可以复用。
4. **结构化结果与人工确认**：正文候选、配图和排版均由用户确认后进入下一阶段。
5. **正文与视觉联动**：图片围绕正式正文段落策划，并保留准确插入位置。
6. **内容资产沉淀**：账号声音、素材库、排版模板和复盘记录共同服务后续创作。

## 部署架构

- 阿里云轻量应用服务器，Ubuntu 24.04
- Nginx + React + TypeScript
- Fastify + Node.js 22
- PostgreSQL 16 + Redis 7 + BullMQ Worker
- Chrome/Playwright 网页读取
- systemd 服务管理

## 当前边界与后续计划

- 当前测试地址为 HTTP，正式开放前将绑定域名并启用 HTTPS。
- 当前复盘台账支持公开页面可读取的标题、封面、发布时间、阅读、点赞、转发等字段；曝光、播放、收藏、评论和新增关注等字段按来源和权限展示，无法获取时显示为空。
- 复盘记录由用户填写总结、亮点、问题和下一步，作为后续创作时的人工参考资产；系统不会自动把复盘结论改写成新的写作规则。
- 后续将根据开放测试反馈继续优化创作效率、内容复盘和多平台派生能力。
