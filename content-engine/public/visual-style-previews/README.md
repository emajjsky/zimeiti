# Visual style previews

These images are generated with `scripts/generate-visual-style-previews.ps1` through the `apimart-imagegen` skill.

Each image is a full-bleed 4:3 art-direction reference for the same creator workflow scene. They intentionally avoid readable text, logos, UI mockups, cards, charts, split panels, and platform collage layouts so the style picker shows visual direction instead of fixed copywriting.

The current set contains 13 manually reviewed 2K PNG previews.
