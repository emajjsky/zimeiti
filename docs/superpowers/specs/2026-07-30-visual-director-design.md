# 视觉导演设计规格

## 目标

把配图页从“手工修改生图提示词”升级为面向自媒体创作者的视觉策划工作台。系统读取当前平台文案，自动决定每个图片位的表达任务、视觉结构、内容结构、版式模板和搜索词；用户确认或微调后，再选择公开图片、项目素材或 AI 生成。

## 产品原则

- 先策划，后找图或生图；进入页面和切换图片位都不得自动搜索、自动生成或消耗额度。
- 项目默认风格保证统一，单张图片可以覆盖，并可随时恢复项目默认。
- 提示词由结构化方案编译生成，只在高级设置中出现。
- 搜图、文生图、参考图生图都是实际可执行能力，不展示无法执行的假入口。
- 已有方案、最终图片绑定和刷新恢复继续有效；旧版方案升级时不得丢失最终图片。

## 方案选择

采用混合型视觉导演：确定性规则负责平台比例、内容信号和安全约束；结构化策划负责思维导图节点、流程步骤、时间线事件和对比项；百炼 CLI 负责文生图或参考图生图。后续可将规则产生的初稿交给项目 Agent 深化，但本期不以 Agent 是否可用阻断配图。

## 风格继承

视觉设置采用两层继承：

1. `styleProfile` 保存当前平台项目的默认风格。
2. 每个 `plan item` 的 `stylePreset` 为 `INHERIT` 或明确风格。

第一版风格预设：清新杂志、波普怀旧、极简知识图、科技媒体、纪实报道。单图选择 `INHERIT` 时，提示词始终使用项目默认；修改项目默认后，所有继承项同步生效。单图覆盖不受项目默认变更影响。

## 视觉结构

支持以下结构：

- `NEWS_PHOTO`：新闻资料图
- `HERO_VISUAL`：人物或物品主视觉
- `SCENE`：真实使用或生活场景
- `CONCEPT_DIAGRAM`：概念关系示意
- `MIND_MAP`：主题、分类、组成和知识体系
- `FLOWCHART`：步骤、方法、路径和工作流
- `TIMELINE`：年份、阶段和事件进程
- `COMPARISON`：方案、前后和优劣对比
- `DATA_CHART`：正文有明确数字时的数据图表
- `INFO_CARD`：结论和知识要点
- `CHECKLIST_CARD`：清单和行动步骤
- `QUOTE_CARD`：有明确出处的引语

规则必须避免把没有数值的趋势描述生成为数据图，也不得为引语卡片虚构人物或出处。

## 数据结构

平台视觉交付新增：

```ts
interface CreativeVisualStyleProfile {
  preset: 'FRESH_EDITORIAL' | 'RETRO_POP' | 'MINIMAL_KNOWLEDGE' | 'TECH_MEDIA' | 'DOCUMENTARY';
}
```

每个图片位新增：

```ts
interface CreativeVisualReference {
  referenceId: string;
  uses: ('COLOR' | 'COMPOSITION' | 'LAYOUT' | 'TEXTURE' | 'SUBJECT')[];
}

interface CreativeVisualPlanItem {
  stylePreset: 'INHERIT' | CreativeVisualStyleProfile['preset'];
  templatePreset: string;
  sourceExcerpt: string;
  contentBlocks: { label: string; detail: string }[];
  references: CreativeVisualReference[];
}
```

提示词不作为设计事实来源。用户修改视觉类型、模板、风格、结构内容或参考图后，系统重新编译提示词并自动保存。

## 用户界面

页面继续保持左侧图片位列表和右侧任务区，不增加新的主导航。

- 页面头部：图片数量、项目默认风格、重新规划。
- 任务头部：图片位、插入位置、系统建议的视觉类型和表达目的。
- 获取方式：搜图、AI 生图、项目素材。
- AI 生图主控制：视觉结构、版式模板、风格继承、参考图、比例、生成按钮。
- “查看策划”：折叠展示原文依据和结构内容，允许按行调整。
- “高级设置”：只放最终提示词。禁止项直接进入最终提示词，不再维护独立负面提示词。
- 参考图：从项目图片素材中选择，最多三张；每张指定参考维度，可移除。

## 真实生成行为

- 没有参考图时调用 `bailian image generate`，使用 `TEXT_TO_IMAGE` 策略。
- 有参考图时调用 `bailian image edit --image ...`，优先使用 `IMAGE_TO_IMAGE` 策略；未配置时可使用当前支持图生图的文生图模型。
- 本地项目文件使用服务器绝对文件路径，公开链接使用 HTTPS URL。
- 参考图只参与当前图片位生成，不会被当作最终图片绑定。
- 成功结果作为新的项目视觉素材保存并绑定当前图片位；失败保留策划和参考图，用户可重试。

## 兼容与错误处理

- 视觉方案版本升级为 4。
- v3 方案升级时保留 `assetReferenceId`、尺寸、用户编辑的目的和信息点，并补齐新字段。
- 参考图不存在、不属于项目或不是图片时，API 返回明确错误。
- 没有配置对应模型时，提示用户前往“模型与 API”，不吞掉 CLI 错误。
- 任何保存失败都显示在当前工作台，且不得重置当前图片位。

## 验收标准

- 包含“分类/体系”的正文会规划出思维导图；包含“步骤/路径”的正文会规划出流程图；包含“前后/A 与 B”的正文会规划出对比图；包含明确年份序列的正文会规划出时间线。
- 每个图片位显示结构、模板、风格和策划内容；切换类型或模板后提示词同步更新并自动保存。
- 修改项目默认风格会影响继承项，不影响已覆盖的单图。
- 选择项目图片作为参考后，生成请求携带参考图并执行图生图，结果可预览、保存和刷新恢复。
- 桌面 1440px 与移动 390px 无横向溢出，核心操作可见且可点击。
