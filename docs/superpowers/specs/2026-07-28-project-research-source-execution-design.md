# 项目研究来源执行设计

## 目标

把研究计划中的 `SEARCH_WEB`、`READ_LINK` 和 `ASK_USER` 从静态建议变成可控、可恢复、可审计的项目动作。用户确认后，系统真实调用已配置的检索 API 或公开网页读取器，保存来源快照和失败原因，但本切片不调用事实核验模型，不把来源摘要冒充为证据结论。

## 产品边界

- 入口只出现在已生成的研究计划产物中，名称为“准备查找资料”。
- 不新增独立搜索页，不把发现页的搜索表单搬进创作页。
- `SEARCH_WEB` 使用工作空间已保存的 Tavily Key；没有 Key 时在准备阶段阻断并给出设置入口。
- `READ_LINK` 只接受研究计划中明确的公开 HTTP(S) 链接；普通网页使用轻量读取，公众号公开文章可使用现有受限 Playwright 回退。
- `ASK_USER` 不自动执行，只保存为“需要补充”，不得生成伪来源。
- 登录、验证码、付费墙、权限不明、局域网地址和非网页内容均停止读取并记录原因。
- 自动测试不得请求 Tavily、真实网页、百炼或媒体接口。

## 用户流程

1. 用户在研究页生成研究计划。
2. 用户打开计划，查看待回答问题、待核验主张和下一步动作。
3. 用户点击“准备查找资料”。系统创建待确认运行，不调用外部服务。
4. 确认卡展示检索次数、链接读取次数、人工补充数、使用工具和写入范围。
5. 用户点击“确认执行”后任务进入队列。
6. Worker 逐项执行，保存每条来源的标题、URL、来源名、摘要、获取时间、对应动作和状态。
7. 完成后生成“来源结果”产物。成功、需人工处理和失败结果分开展示，刷新后保持。
8. 用户可返回资料区补充自己的内容，也可继续下一切片的 AI 证据分析。

## 状态与数据

### 运行

来源执行复用 `generation_runs`，动作版本为 `project-research-sources:1.0.0`，状态继续使用 `DRAFT → QUEUED → RUNNING → SUCCEEDED/FAILED/CANCELLED`。同一项目研究阶段只能有一个活动运行。

### 来源快照

新增 `project_research_source_runs` 和 `project_research_sources`：

- 执行记录关联项目、研究计划、生成运行和结果产物。
- 来源状态为 `CAPTURED`、`NEEDS_USER` 或 `FAILED`。
- 搜索结果最多保存每个动作前 5 条，整次最多 20 条。
- URL 按规范化地址去重，但保留首次命中的动作索引。
- 摘要最多 2,000 字；不保存完整网页 HTML、Cookie 或登录态。

## 组件与接口

- `server/services/project-research-sources.cjs`：动作归一化、运行确认摘要、搜索/读取结果归一化和结果视图。
- `POST /api/v1/creative/projects/:projectId/research/sources/prepare`：读取最新研究计划，校验 Tavily 凭据，创建 DRAFT。
- `POST /api/v1/creative/research-source-runs/:id/confirm`：创建 `PROJECT_RESEARCH_SOURCES` Job。
- `POST /api/v1/creative/research-source-runs/:id/cancel`：取消未执行运行。
- Worker 负责真实外部调用和来源落库；API 请求线程不直接执行长任务。
- `ProjectAgent` 继续承载确认卡、轮询、错误和产物预览。

## 界面

- 研究计划预览底部只增加一个主动作“准备查找资料”。
- 来源运行确认卡不显示不存在的模型或提示词，改为显示“网页搜索 / 链接读取 / 需补充”和工具。
- 来源结果使用紧凑纵向列表，不再套第二层卡片；每条显示状态、标题、来源、时间、摘要和可打开的原链接。
- 页面沿用现有浅色波普怀旧清新视觉，设计参数为 `DESIGN_VARIANCE 4 / MOTION_INTENSITY 2 / VISUAL_DENSITY 7`，不增加装饰动画。

## 错误处理

- Tavily Key 缺失或未验证：prepare 返回可读错误，不创建运行。
- 单个动作失败不终止整次任务；保存 `FAILED` 项并继续其余动作。
- 全部自动动作失败时运行标记 `FAILED`，但失败快照仍可读取。
- `ASK_USER` 永远记录为 `NEEDS_USER`，不计入执行失败。
- 队列或数据库失败沿用现有运行失败和调用日志机制。

## 验收

- 研究计划有 `SEARCH_WEB` 时可准备来源任务，确认前没有外部请求。
- 确认卡数量与计划动作一致，且不显示虚假的模型字段。
- Mock Tavily 与网页读取结果可保存、展示并在刷新后恢复。
- 公众号验证页、登录页或读取失败被标为需处理/失败，不伪造正文。
- 来源结果明确标注“尚未完成事实核验”。
- 1024px 和 390px 无横向溢出。
