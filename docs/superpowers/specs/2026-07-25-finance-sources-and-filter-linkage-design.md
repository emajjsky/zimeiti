# 财经来源与筛选联动设计

## 1. 目标

补足财经情报的来源广度，同时修正题材与关键词可以形成无效组合的问题。用户选择“财经”后，应看到财经关键词和财经内容，而不是继续保留“篮球”等其它题材关键词并得到空结果。

本轮只处理来源目录、主动搜索预设和筛选联动，不接入实时行情交易接口，不采集付费内容，不做 AI 热点分析。

## 2. 来源分层

### 2.1 自动更新

自动来源必须满足以下条件：

- 官方或来源方明确公开的 RSS、Atom 或开放接口。
- 本地真实请求可访问，内容可由现有解析器读取。
- 最近仍有更新，不能只因为 HTTP 200 就认为可用。
- 授权条款允许用于用户自己的资讯聚合，不把全文重新发布给公众。

首批保留中国新闻网财经和 36Kr。新浪财经公开的旧 RSS 虽然仍有部分地址返回 HTTP 200，但最新内容停留在 2018 年，不进入默认自动来源。

国际财经可增加仍在更新的官方 RSS：

| 来源 | 类型 | 默认题材 |
| --- | --- | --- |
| 美联储新闻稿 | 官方 RSS | 财经 |
| 美国 SEC 新闻稿 | 官方 RSS | 财经 |
| 欧洲央行新闻稿 | 官方 RSS | 财经 |

国际官方源默认语言为英文，单个来源失败不得阻断其它来源。

### 2.2 财经媒体主动搜索

以下来源当前公开网页可访问，但没有经过验证的稳定开放 RSS/API 合同，因此只作为 Tavily 限定域名搜索预设：

| 渠道 | 域名 |
| --- | --- |
| 腾讯财经 | `finance.qq.com`、`new.qq.com` |
| 新浪财经 | `finance.sina.com.cn` |
| 同花顺财经 | `10jqka.com.cn` |
| 东方财富 | `eastmoney.com` |
| 财联社 | `cls.cn` |

用户必须主动输入检索词。候选结果需要点击“加入热点池”后才入库，不能由系统未确认地定时抓取。

### 2.3 官方公告与宏观数据

官方一手信息作为独立搜索预设，不与普通财经媒体混在一起：

| 类型 | 来源 |
| --- | --- |
| 国内宏观与监管 | 中国人民银行、国家统计局、证监会、国家外汇管理局 |
| 交易所公告 | 上交所、深交所、北交所、港交所 |
| 公司投资者关系 | 阿里巴巴、腾讯等公司的财报、公告和业绩材料 |

对应限定域名为：`pbc.gov.cn`、`stats.gov.cn`、`csrc.gov.cn`、`safe.gov.cn`、`sse.com.cn`、`szse.cn`、`bse.cn`、`hkex.com.hk`、`hkexnews.hk`、`alibabagroup.com`、`tencent.com`。

阿里巴巴和腾讯投资者关系页用于核验公司财报与公告，不作为综合财经新闻流。阿里云、腾讯云市场中的财经 API 只有在确认具体数据商、授权范围、费用和再分发限制后才能作为授权数据源接入。

## 3. 筛选联动

筛选逻辑保持交集语义，但阻止无效组合长期残留：

1. 关键词选项先按 30 天时间范围过滤。
2. 选择具体题材后，关键词选项只来自该题材文章。
3. 切换题材时，如果当前关键词不属于新题材，自动恢复为“全部关键词”。
4. 切换时间范围后，如果当前关键词在新时间范围不存在，也自动恢复为“全部关键词”。
5. 关键词仍有效时必须保留，避免用户每次切换都丢失有意义的条件。
6. 空结果区域提供“清除关键词”操作，仅在确实存在关键词条件时出现。

例如：当前为“体育 + 篮球”，用户把题材改为“财经”，系统自动改成“财经 + 全部关键词”，财经内容立即出现。

联动规则实现为独立纯函数，而不是继续堆在页面 JSX 中：

- `deriveKeywordOptions(items, timeRange, category)` 返回当前范围可选关键词。
- `reconcileKeywordFilter(currentKeyword, keywordOptions)` 保留有效关键词或返回 `ALL`。

页面用 `useEffect` 在关键词选项变化后执行复位。纯函数使用真实数据数组测试，不使用源码字符串断言。

## 4. 页面归属

- “情报源 → 自动来源”：展示可定时更新的 RSS/官方开放源。
- “情报源 → 辅助渠道”：增加 `FINANCE_MEDIA`（财经媒体）和 `FINANCE_OFFICIAL`（官方公告）两个主动搜索入口。
- “网页搜索”：渠道预设增加 `defaultCategory`，接收域名后将默认题材设为“财经”；用户仍可手动调整。
- “热点情报”：实现题材、时间和关键词联动，不增加新的筛选控件。
- “模型与 API → 检索 API”：继续只管理 Tavily Key，不在情报源页面重复配置。

## 5. 数据与安全

- RSS、搜索和剪藏继续使用统一分类器与规范化 URL 去重。
- 搜索预设只保存公开域名，不保存登录状态、Cookie 或账号密码。
- 不绕过验证码、登录、付费墙、反爬限制或 robots/站点访问规则。
- 新闻内容只保存标题、摘要、来源、时间、原文 URL、分类和关键词；发布内容必须引用原文并重新创作。
- 行情价格、财务指标等结构化数据后续单独设计授权 API，不从新闻网页解析冒充行情数据。

## 6. 错误处理

- RSS 返回成功但内容长期停更时标记为“不适合作为默认源”，而不是继续加入目录。
- Tavily 未配置时，财经媒体和官方公告入口跳转到检索 API 设置。
- 某一限定域名无搜索结果时允许切换到全网搜索，但不自动扩大搜索范围。
- 题材切换清除关键词时不弹提示，筛选控件的可见值就是最终状态。

## 7. 验收条件

1. 从“体育 + 篮球”切换到“财经”后，关键词自动变为“全部关键词”。
2. 选择“财经”时，关键词下拉只出现财经文章实际命中的关键词。
3. 切换时间范围导致关键词不存在时，关键词自动复位。
4. 中国新闻网财经、36Kr继续作为国内财经自动源。
5. 美联储、美国 SEC、欧洲央行官方 RSS 可加入并独立刷新。
6. 腾讯财经、新浪财经、同花顺、东方财富、财联社只显示为主动搜索渠道。
7. 阿里巴巴、腾讯投资者关系页归入官方公告搜索，不显示为综合财经 RSS。
8. 自动化测试、类型检查、生产构建通过；桌面和手机视口无横向溢出。

## 8. 实施顺序

1. 为题材和关键词联动写失败测试并修复。
2. 为财经来源分层目录写失败测试。
3. 添加经验证的国际官方财经 RSS。
4. 添加财经媒体和官方公告搜索预设。
5. 更新 PRD、PLAN、IMPLEMENT 和验收记录。
6. 使用真实 RSS 与浏览器完成刷新和筛选验收。
