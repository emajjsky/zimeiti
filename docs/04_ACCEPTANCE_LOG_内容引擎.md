## A4. 当前可由用户验收

1. 打开 `http://127.0.0.1:5173`，注册一个工作空间并完成首次设置。
2. 在“情报源”中添加国内或国际 RSS 来源，回到发现页刷新热点。
3. 在“检索 API”中保存 Tavily Key，在网页搜索中主动查询并加入一条候选结果。
4. 在“模型与 API → 核心 Agent”中保存百炼 Key 与规划模型。
5. 在剪藏链接页粘贴一条可公开读取的文章链接；微信验证码页应被明确拒绝，不会尝试绕过。
