## A2. 未验收项

- 桌面端 IPC 保存/重启后的完整 UI 端到端自动化。
- 真实 RSS 网络采集在 Electron 进程中的成功、失败、超时回归。
- 飞书 OAuth、模板创建、字段 ID 映射和单向同步。
- 内容素材、视频任务、发布预检和浏览器辅助发布。

## A3. 已知限制

- 浏览器开发模式没有 Electron `contextBridge`，因此使用 localStorage 回退验证页面交互；它不能替代桌面端 SQLite IPC 验收。
- 选题会仅按用户选择的平台生成版本；验收样例未勾选视频号，因此生成公众号和小红书两个版本，符合当前设计。

## A4. 验收反馈后的交互修订

- 设置页拆分为“1 情报源”和“2 飞书内容库”两个任务入口，默认展示情报源。
- 情报源页增加“添加示例源”路径，用户可以先验证热点流程，再替换为自己的可信来源。
- 飞书模板页不再和情报源同时出现；OAuth 未实现期间只允许配置和预览，不暗示可以创建。

## A5. 热点刷新反馈修订

- 刷新按钮执行中显示“正在刷新”及旋转状态，并防止重复点击。
- 完成后明确显示“发现 N 条新热点”“没有新内容”或“来源失败”的结果；部分失败不覆盖成功结果。
- RSS 文本在入库前解码常见 HTML 和数值实体，避免标题出现 `&#8217;` 等残留。
- 历史热点加载时也执行相同标准化，并按“来源 + 标准化标题”去重，防止编码修复前后的同一资讯重复出现。
- 刷新发现新资讯后，自动选中第一条新增结果，确保详情面板与列表当前上下文一致。
- 应用加载已有热点时默认选中列表第一条，避免详情仍显示不可见的旧演示热点。

## A6. 链接剪藏

- 新增“剪藏链接”入口，用户可主动保存公众号文章、公开网页和报告链接到热点池。
- 记录链接、标题、来源、摘要、题材和备注；明确不绕过访问限制。

## A7. 模型与 API 配置

### 已完成

- 独立模型配置页：供应商选择、连接字段、用途选择、连接状态和已保存连接列表。
- 支持阿里云百炼、硅基流动、火山方舟、Kimi、智谱 AI、OpenAI 及自定义 OpenAI 兼容接口。
- API Key 经 Electron `safeStorage` 加密后保存，页面重新打开不会回显密钥。
- 支持保存、连通性检查、编辑已有连接与移除连接。
- 供应商切换时使用一次性 Anime.js 表单层级动效；系统启用“减少动态效果”时不播放。

### 待用户验收

1. 打开桌面端左侧“模型与 API”。
2. 选择已拥有 Key 的供应商，核对预填 API 地址和模型名称后输入 API Key。
3. 点击“保存并检查”，确认看到成功或可行动的失败原因。
4. 退出并重开桌面端，确认列表仍保留连接且 API Key 不显示。

### 已知限制

- 连通性检查依赖供应商提供兼容的 `/models` 目录接口；部分私有网关可能需要先保存后改为实际模型调用检查，后续将作为适配器能力补齐。
- 文本模型尚未接入热点摘要、筛选和选题推荐执行链路。

## A8. 百炼 CLI 能力中心与外部 API 重构

### 已完成

- 安装 `bailian-cli@1.10.1` 作为桌面应用依赖，并验证可由 Electron 运行时执行 `bl 1.10.1`。
- 已通过 `npm run package:dir` 生成 Windows 目录包；验证包内 `app.asar` 包含 CLI 及其运行依赖，并能由 `win-unpacked/内容引擎.exe` 执行 `bl 1.10.1`。
- 百炼 Key 与外部 API Key 分表保存，均使用 Electron `safeStorage` 加密；百炼 Key 不写入 CLI 的全局配置文件。
- 页面拆分为百炼 CLI 能力中心、外部 API 列表、新增/编辑外部 API 三个独立界面。
- 百炼主操作面已移除能力原理、密钥存储机制和检查流程说明，仅保留状态、能力范围、访问凭证与操作；相关说明按需放入帮助或错误详情。
- 访问凭证区显式展示“待输入 / 已输入 / 已保存”状态；首次未输入 Key 时保存和检查操作不可用。
- 真实 Electron 复验通过：重启主进程后初始状态为“待输入”，输入框显示“粘贴 API Key”，保存/检查按钮禁用；旧窗口不会热更新 Electron 主进程逻辑。
- 百炼支持自动、文字、视觉、音频、视频五种当前能力范围；具体模型与 CLI 命令留给后续 Agent Skill 受控调度。
- 百炼检查同时验证内置 CLI 可启动与 Key 可访问百炼模型目录，不触发生成任务。
- 检查失败会将失败状态写回本地并抛出 HTTP 状态、百炼返回的非敏感错误摘要或网络错误；界面不再吞掉原因后显示模糊失败信息。

### 待用户验收

1. 重启桌面端后打开“模型与 API”，应默认进入“百炼 CLI”。
2. 配置百炼 Key，点击“保存并检查”，确认状态变为“已验证”。
3. 切到“外部 API”，确认已有硅基流动连接只出现在列表中，点击“编辑”才进入独立编辑页。
4. 返回百炼页，确认外部 API 不会与百炼 Key 或能力范围混在同一表单中。

### 尚未实现

- CLI 的版本升级策略与安装包签名。
- Agent 对话实际选择百炼 CLI 子命令、模型推荐、成本预估、任务取消和生成资产归档。
