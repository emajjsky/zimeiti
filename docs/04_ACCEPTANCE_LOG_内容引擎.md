## A4. 当前可由用户验收

1. 打开 `http://127.0.0.1:5173`，注册一个工作空间并完成首次设置。
2. 在“设置 → 资讯来源”中添加国际财经组，回到“发现 → 热点情报”刷新并选择财经题材。
3. 在“发现 → 网络搜索”中选择财经媒体或官方公告来源范围，确认未配置 Tavily 时可跳转到“设置 → 模型与 API → 检索 API”。
4. 在“设置 → 模型与 API → 检索 API”中保存 Tavily Key，回到网络搜索主动查询并加入一条候选结果。
5. 在“设置 → 模型与 API → 百炼”中保存百炼 Key，再到“核心 Agent”选择规划模型。
6. 在“发现 → 导入链接”中粘贴一条可公开读取的文章链接；微信验证码页应被明确拒绝，不会尝试绕过。

### A25.1 可执行验收用例

1. 新建 V2 测试项目，输入一份用户草稿、两条公开参考链接、一张用户自有图片和一张仅参考色彩/构图的视觉参考图；分别标记原稿、事实、结构和视觉 Scope，刷新后分类保持。
2. Agent 生成研究计划，确认后读取两条公开来源；至少一个关键事实关联一个第一方/官方来源。挑战页、登录页、付费墙和 robots/条款禁止场景必须返回人工处理，不得切换执行器继续尝试。
3. 采用内容母版后创建公众号和小红书两个平台版本。两个版本分别保存篇幅、钩子、CTA 和渠道规则，切换平台不得串用。
4. 人工修改公众号正文后再更新内容母版。公众号正式正文必须保持不变，只产生“母版有更新”和可查看差异的候选；用户采用候选后才创建新版本。
5. 公众号配图计划至少采用一张用户已有图片，并基于视觉参考图生成或 Mock 一张封面候选。视觉参考 Scope 不得进入事实提示词；版权状态为 `UNKNOWN`、授权撤销或素材缺失时阻断导出。
6. 五类审核阻断条件：未解决的关键事实冲突/待核验陈述、与参考资料高相似且未引用、平台硬规则冲突、缺少渠道必需封面/发布字段、采用素材版权未知或失效。用户删除、弱化或补证后才可重新审核。
7. 审核通过后导出包至少包含 `manifest.json`、正文 Markdown、公众号 HTML、`assets/` 封面和正文图片、`sources.json`、`review.json`；清单中的哈希、版本 ID 和文件必须一致。
8. 旧项目保持 `LEGACY_V1`。迁移预览不得写数据库；用户确认后才创建 V2 对象，迁移过程不调用模型、不覆盖正文、不删除历史运行，失败时整体回滚。
