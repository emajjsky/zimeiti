## A4. 当前可由用户验收

1. 打开 `http://127.0.0.1:5173`，注册一个工作空间并完成首次设置。
2. 在“情报源 → 自动来源”中添加国际财经组，回到热点页刷新并选择财经题材。
3. 在“情报源 → 辅助渠道”中检查财经媒体和官方公告入口，进入网页搜索后题材应默认为财经。
4. 在“模型与 API → 检索 API”中保存 Tavily Key，在网页搜索中主动查询并加入一条候选结果。
5. 在“模型与 API → 核心 Agent”中保存百炼 Key 与规划模型。
6. 在剪藏链接页粘贴一条可公开读取的文章链接；微信验证码页应被明确拒绝，不会尝试绕过。

## A5. 已知限制

- 当前前端仍使用工作空间快照作为迁移桥；后续需迁移为领域 API 和表。
- 当前开发环境仅适用于本地个人测试，不是生产部署。
- 用户真实 Tavily Key、飞书 OAuth、百炼内容生成和平台发布均未完成真实用户验收。
