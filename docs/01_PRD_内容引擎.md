# 内容引擎 PRD

> 状态：Draft v0.1  
> 日期：2026-07-22  
> 产品形态：桌面客户端优先，云端控制与同步中心辅助

## 1. 产品定义

内容引擎是一台面向中文创作者与小团队的 AI 内容运营工作台。它将“发现信息、判断选题、生产多平台内容、制作本地视频、人工确认发布、复盘迭代”组织成一个连续的内容生产闭环。

产品适用于 AI、财经、历史、人文、国学、教育等多种题材。AI 是生产能力，不是内容垂类限制。

### 1.1 一句话价值主张

让一台电脑成为创作者的内容工厂：云端持续供给情报，桌面端用本地素材与算力把情报变成可发布的图文和视频内容。

### 1.2 核心设计决策

- **桌面端优先**：数字人、混剪、字幕、渲染和本地素材管理需要本机算力与文件系统。
- **云端持续在线**：热点采集、飞书同步、授权 API 数据读取、跨设备元数据同步不依赖用户电脑开机。
- **Web 是控制与协作能力，不是首期主工作台**：未来可提供轻量 Web 审批和查看，但创作主体验在桌面端。
- **飞书 Base 是协作出口，不是主数据库**：用户可在飞书查看资讯、选题、审核和排期；内容、任务、素材索引和授权仍由产品维护。
- **半自动发布**：官方 API 优先；无可靠 API 时由本地浏览器插件填充内容，用户在平台中最终确认发布。

## 2. 目标与非目标

### 2.1 V0.1 目标

1. 创作者每天在 10 分钟内处理热点并确定今天要做的选题。
2. 一个选题在 30 分钟内形成公众号、小红书、视频号的内容包初稿。
3. 本地客户端可完成数字人口播/混剪任务的准备、排队、渲染和导出。
4. 让内容从发现到发布全过程可追踪，知道当前卡在哪一步。
5. 以用户自身账号进行 dogfooding，验证“AI 工具科普”内容链路，但数据模型不锁定题材。

### 2.2 非目标

- 不在 V0.1 承诺全平台全自动发布。
- 不托管平台账号密码、Cookie 或绕过验证码。
- 不自研图像、语音、数字人或视频基础模型。
- 不在 V0.1 做复杂多级组织、财务、CRM、广告投放或企业审批系统。
- 不把飞书 Base 作为唯一数据源或任务执行系统。

### 2.3 V0.1 范围与能力矩阵

| 能力 | V0.1 交付 | 数据模型预留 / P1 |
| --- | --- | --- |
| 用户与协作 | 单个 Owner、单工作空间、多设备使用；飞书评论作为外部协作输入 | 产品内成员邀请、角色、分配与多人实时协作 |
| 飞书 | 热点与选题的单向镜像；人工备注可通过显式“导入意见”回写 | 自动审核意见回写、排期/复盘双向同步、复杂字段映射修复 |
| 公众号 | 文章 HTML/素材包导出、发布预检、打开后台 | 官方 OAuth/API 或稳定浏览器预填能力按平台政策评估 |
| 小红书 | 封面/分页图导出、文案/标签复制、发布预检 | 已登录浏览器辅助预填和数据读取 |
| 视频号 | 口播稿/分镜/视频文件导出、发布预检 | 浏览器辅助与官方能力接入 |
| 视频 | 脚本、场景、字幕、FFmpeg 基础合成、Hyperframer 导出 | 具体数字人/视频供应商直连、云端渲染 |
| 数据复盘 | 手工录入发布结果与基础结论 | 官方 API 自动数据读取和跨平台归因 |

**V0.1 的“三端内容包”定义**：公众号文章初稿与排版输出、小红书封面及分页图文草稿、视频号口播稿/分镜/字幕稿；不要求在 30 分钟目标内生成最终视频成片。

## 3. 目标用户与场景

### 3.1 用户角色

| 角色 | 主要目标 | V0.1 支持方式 |
| --- | --- | --- |
| 个人创作者 | 稳定更新、降低生产成本、复用内容资产 | 完整主流程 |
| 小型内容团队主理人 | 管理选题、审核内容、安排发布 | 工作空间、审核状态、飞书同步 |
| 编辑/运营协作者 | 补资料、审核、排期、查看结果 | 飞书协作与轻量桌面权限，P1 加强 |

### 3.2 核心使用场景

1. **每日选题**：云端收集题材热点，用户在“今天/发现”中筛选并创建选题。
2. **图文生产**：从选题生成公众号长文、小红书分页图文和视频口播稿。
3. **视频生产**：用本地 GPU 处理数字人、配音、字幕、B-roll、混剪和渲染。
4. **发布审核**：将内容排入日历，进行规格与事实检查，打开平台后台预填内容。
5. **复盘学习**：将平台可得数据或手工数据与内容项目关联，形成下一轮选题建议。

## 4. 业务对象与内容模型

系统围绕“内容项目”而非单篇文章或单个账号建模。

```mermaid
flowchart LR
    A[题材与信息源] --> B[热点资讯]
    B --> C[选题]
    C --> D[内容项目]
    D --> E[平台内容版本]
    E --> F[发布任务]
    F --> G[已发布内容]
    G --> H[指标与复盘]
    H --> C
```

| 对象 | 定义 | 关键关系 |
| --- | --- | --- |
| 题材 | 一组关键词、来源、栏目和内容策略 | 拥有多个信息源与选题 |
| 热点资讯 | 单条经采集、去重、摘要后的情报 | 可创建多个选题 |
| 选题 | 可被判断和立项的内容机会 | 被采纳后创建一个内容项目 |
| 内容项目 | 一次完整内容生产的工作单元 | 包含多个平台版本、素材与任务 |
| 平台内容版本 | 公众号/小红书/视频号各自的可发布版本 | 有独立草稿、审核、发布记录 |
| 素材资产 | 图片、视频、音频、文档、引用与品牌素材 | 可被多个项目复用 |
| 发布任务 | 某个平台版本的一次排期或人工发布尝试 | 关联账号与最终平台内容 ID |
| 复盘结论 | 从内容指标提炼的可复用规律 | 回流到题材、栏目、模板与选题 |

## 5. 内容生命周期与状态机

### 5.1 热点资讯

`新收集 → 已查看 → 已收藏 / 已忽略 / 已转选题`

### 5.2 选题

`待判断 → 已采纳 → 已立项 → 已废弃`

### 5.3 内容项目

`策划中 → 写作中 → 视觉制作中 → 视频制作中 → 待审核 → 待排期 → 已发布 → 待复盘 → 已归档`

### 5.4 平台内容版本与发布任务

`草稿 → 已预检 → 等待人工确认 → 已发布`  
异常分支：`发布失败 → 待重试 / 已取消`

### 5.5 发布任务（独立于内容版本）

`待排期 → 已排期 → 预检中 → 等待用户确认 → 已打开平台后台 → 已提交 → 已确认发布`  
异常分支：`预检阻断 / 发布失败 → 待重试 / 已取消`

一个平台版本可对应多次发布任务（改期、重试、换账号）。V0.1 的“已确认发布”定义为：用户明确在客户端确认平台已提交并填写链接或平台内容 ID；不将“打开平台后台”视为发布成功。

### 5.6 项目状态聚合规则

- 只要任一必选平台版本仍在生产，项目保持对应生产阶段。
- 所有必选版本通过审核后，项目进入“待排期”。
- 至少一个发布任务“已确认发布”且其余必选版本未发布时，项目显示“部分已发布”。
- 全部必选版本已确认发布后，项目进入“已发布/待复盘”。
- 任一版本失败不会自动把项目设为失败；项目显示“存在需处理任务”。

状态不得混用。例如“视频制作中”是项目状态，“草稿”是平台版本状态，“等待本机”是渲染任务状态。

## 7. 功能需求

### F1. 首次启动与工作空间配置（P0）

首次启动通过 5 步向导完成：

1. 创建工作空间与账号名称。
2. 选择题材与内容目标。
3. 设置默认发布平台与内容风格。
4. 可选配置飞书内容库模板；授权和创建在后续独立步骤完成，不要求填写 Base URL。
5. 设置本地素材目录、模型目录和 GPU 服务检测。

设置页面遵循单任务顺序：先配置情报源，再配置飞书内容库模板；不在同一页面要求用户同时理解 RSS、字段映射和 OAuth。

### F2. 情报与热点（P0）

- 用户按题材配置关键词、排除词、来源、频率和飞书目标表。
- 支持用户主动链接剪藏：保存公众号文章、公开网页或报告的链接、来源、标题、摘要、题材和备注；不绕过登录、付费墙、验证码或访问限制。
- 云端按计划采集公开 RSS、合规搜索源、用户订阅网页和可授权来源。
- 对热点进行去重、聚类、摘要、题材归类、时效和可信度标注。
- 热点详情必须支持：查看来源、收藏、忽略、加入选题池、创建选题。
- 来源运行日志仅在来源详情/自动化记录中查看，不作为日常发现页的主内容。

### F3. 选题与栏目（P0）

- 支持内容支柱、栏目和系列选题。
- 选题列表默认仅显示：选题、题材、目标平台、时效、状态、计划日期。
- 选题详情包含 Brief、核心观点、目标受众、关联情报、内容策略、风险与核验。
- “确认立项”会创建内容项目并保留与原始资讯的关联。

### F4. 内容项目与平台版本（P0）

- 内容项目采用固定五步：Brief、写作、视觉、视频、审核。
- 每个项目至少可生成公众号、小红书、视频号三个版本；用户可按需关闭某个平台。
- 写作页支持标题、摘要、正文、引用、图片占位、平台改写、版本历史和事实待确认项。
- AI 建议作为可折叠辅助区，不得占据主编辑区。
- 项目需保存个人/账号的风格资产：语气、标题习惯、禁用词、栏目、CTA、封面偏好。

### F5. 视觉与素材（P0）

- 小红书支持封面与多页知识卡；每页可生成多个方案、替换素材、编辑文字和保存版本。
- 素材库支持本地/云端索引、标签、比例、时长、来源、版权、使用次数和项目关联。
- 大型原始文件默认本地保存；云端保存缩略图、元数据和必要协作副本。
- 每个引用和图片应保留来源与版权状态。

### F6. 本地视频工作台（P0）

- 支持场景列表、口播稿、数字人、音色、字幕、背景素材、B-roll、音乐和时间轴。
- 通过本地 Sidecar 调度 FFmpeg、语音/字幕工具、数字人/视频供应商适配器。
- 支持“本机渲染”和“导出 Hyperframer 素材包”。
- 显示任务状态：等待本机、排队中、渲染中、成功、失败、待重试。
- GPU 状态只在任务页、设置页或异常提示中展示。

### F7. 发布与账号（P0/P1）

- P0：内容日历、发布审核、规格预检、导出/复制、打开平台后台；账号状态仅指本机浏览器是否检测到已登录，不创建云端 OAuth 凭据。
- P1：官方 OAuth 账号连接、已授权平台的发布和数据读取。
- 对无可靠官方 API 的平台，浏览器插件仅处理本机已登录页面的辅助填充，用户必须最终确认。
- 发布预检包含：标题、封面、标签、文件规格、敏感表达、引用/版权、账号状态和待确认事实。

### F8. 飞书 Base 集成（P0）

- P0 提供不连接飞书和镜像模式两种选择；协作模式属于 P1。默认入口为“内容库模板”，不要求用户填写 Base URL。
- 用户先编辑模板并预览将创建的表与字段，再完成飞书 OAuth 授权并最终确认创建；不自动改写用户已有 Base。
- 模板至少创建“热点库”“选题池”“同步日志”，可选“内容排期”“复盘数据”；用户可改表名、增加自定义字段和关闭可选表。
- `content_engine_id` 为受保护的系统字段；字段映射按字段 ID 保存。已有 Base 导入仅作为高级能力，P0 不作为默认路径。
- P0 仅同步热点摘要和选题；用户可手动导入飞书中的备注、标签和是否采纳意见。
- P1 再同步内容摘要、审核状态、排期和复盘，并支持自动回写审核意见。
- 产品需维护 `workspace_id / base_id / table_id / record_id / content_id` 映射；不得用标题匹配记录。

### F9. 数据与复盘（P0/P1）

- P0 支持手工录入发布结果与基础复盘结论；P1 支持官方 API 数据读取。
- 明确标注数据来源与更新时间。
- 默认回答“什么内容值得继续做”，而非堆叠大量指标。
- 复盘至少输出内容表现、栏目表现、平台差异、评论问题和可复用结论。
- 用户可从复盘结论一键创建系列选题。

## 8. 验收标准

1. 新用户可在 15 分钟内完成首次设置并看到第一批热点。
2. 用户可从一条热点在 3 次点击内创建内容项目。
3. 内容项目的公众号、小红书、视频号版本状态可独立追踪。
4. 用户可在不离开桌面端的情况下完成视频脚本、素材准备、渲染任务提交和 Hyperframer 导出。
5. 发布前任何缺失的关键项都可见，并能定位到需修改的内容步骤。
6. 飞书断连或同步失败不会阻塞内容项目的正常编辑。
7. 用户能从已发布内容回到对应项目、版本、素材与复盘结论。

## 9. 核心指标

| 类型 | 指标 | 初期目标 |
| --- | --- | --- |
| 激活 | 完成首次设置并创建首个选题的用户占比 | > 60% |
| 内容效率 | 热点到内容项目的中位时间 | < 10 分钟 |
| 生产效率 | 内容项目到三端初稿的中位时间 | < 30 分钟 |
| 发布完成 | 完成预检并进入发布流程的项目占比 | > 70% |
| 质量 | 生成内容被用户直接采用或轻度编辑采用的比例 | > 50% |
| 稳定性 | 热点收集/飞书同步任务成功率 | > 98% |

### 9.1 事件口径（P0）

| 事件 | 触发条件 | 统计口径 |
| --- | --- | --- |
| `topic_created` | 热点或手工输入创建选题 | 去重后的选题 ID 数 |
| `project_created` | 用户确认立项成功 | 已关联选题的项目数 |
| `bundle_generated` | 三端初稿均生成完成 | 不含最终视频成片 |
| `publish_flow_started` | 通过发布审核并打开平台后台 | 以发布任务 ID 去重 |
| `publish_confirmed` | 用户录入发布链接/平台内容 ID | 平台版本层级统计 |
| `light_edit_adopted` | 用户未重新生成，仅编辑后保留生成结果 | 以版本差异和显式确认判断 |

## 10. 风险与待决事项

## 11. 已冻结实施顺序（2026-07-22）

1. 资讯来源：合规默认来源、RSS、官方数据、链接剪藏、Tavily 候选搜索、去重与智能筛选。
2. 飞书 Base：用户模板、OAuth 创建、热点/选题/项目摘要的单向镜像；飞书不是主数据库。
3. 通用 Agent 创作工作台：对话驱动 Skill 编排，产出解读、改写、排版、视觉与视频任务，并将结果写入内容资产。
4. 平台半自动发布：预检、浏览器预填、用户最终确认和发布记录。
5. 数据跟踪与复盘：先手工数据，后官方 API；输出可执行栏目结论和新选题建议。

当前优先完成第一阶段。任何后续功能都不得绕过资讯来源、引用与内容资产的主数据链路。

- 国内平台的发布与数据能力依赖官方开放范围，必须按平台能力分级，而非统一承诺自动化。
